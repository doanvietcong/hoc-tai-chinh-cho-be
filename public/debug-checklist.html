🔧 Debug trang Pé Ti

Bước 1: Nếu thấy trang này nghĩa là Cloudflare serve static OK. Vấn đề là ở React/Next.js streaming.
Nguyên nhân thường gặp "This page couldn't load":
  1. HTTP/3 (QUIC) issue - Một số trình duyệt/mạng fail với HTTP/3 của Cloudflare
  2. Extension chặn JS - AdBlock, uBlock, NoScript, Privacy Badger...
  3. DNS cache cũ - Cloudflare vừa đổi edge
  4. Network timeout - JS chunks quá lớn, mạng chậm
Bước 2: Thử các cách sau theo thứ tự

Cách A - Tắt HTTP/3 (QUIC):

  1. Mở tab mới, gõ chrome://flags/#enable-quic
  2. Chuyển từ "Default" → "Disabled"
  3. Bấm "Relaunch" để restart Chrome
  4. Thử lại hoc-tai-chinh-cho-be.pages.dev/lesson/money-1

Cách B - DNS flush:

  1. Windows: mở CMD admin, gõ ipconfig /flushdns
  2. Mac: sudo dscacheutil -flushcache

Cách C - Thử trình duyệt khác:

  1. Firefox (em test thấy OK nhất với Cloudflare)
  2. Edge
  3. Brave

Cách D - Test URL không phải /lesson/:

  1. /home - trang chủ, không phải streaming
  2. /play - trang mini-game
  3. /test.html - trang tĩnh (đã chắc chắn OK)
